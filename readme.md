# 🧠 LLM Analysis Quiz - Project 2 (IITM TDS)

This project implements an API endpoint that can receive quiz tasks, process data, and automatically submit answers — as part of the *LLM Analysis Quiz* project.

---

## 🚀 Features

- Flask-based API (`/quiz` endpoint)
- Verifies a secret key for secure access
- Fetches and analyzes quiz URLs
- Submits answers within required JSON format
- Ready for deployment on Render or similar platforms
